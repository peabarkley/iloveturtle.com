# Aiguigu · Comprehensive Turtle Knowledge Website

Aiguigu is a knowledge-based website dedicated to turtle科普, offering fun facts, species comparisons, and practical care guides. The site features a clean, responsive design with bilingual support (Chinese/English) and a user-friendly multi-level structure.

## Features

- **Complete content hierarchy**: From homepage to secondary topic pages, tertiary article lists, and quaternary article details.
- **Bilingual support**: One-click language switch (Chinese/English) covering navigation, titles, and article content (using bilingual blocks).
- **User interaction**: "What else would you like to know?" feedback section on the homepage, and comment sections at the bottom of every article (simulated submission).
- **GEO optimization**: Built-in structured data, evidence-based claims, and localized semantic anchors.
- **Responsive design**: Optimized for mobile, tablet, and desktop.
- **Clean directory structure**: Easy to extend and maintain.

## Tech Stack

- HTML5
- CSS3 (Flexbox/Grid)
- Vanilla JavaScript
- Font Awesome 6 (icons)
- JSON-LD structured data
